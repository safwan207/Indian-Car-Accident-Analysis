This project involved developing a comprehensive Power BI dashboard to analyze road accident trends and contributing factors based on an Indian roads dataset. The dashboard provides a high-level overview of crash statistics to help identify high-risk areas and conditions. 
Key Insights & Visualizations
The dashboard is structured into several analytical modules that break down Total Accidents across multiple dimensions:
Geographical Distribution: A donut chart displays accident volume by major cities, with Chennai (12.88%) and Pune (12.59%) showing the highest percentages in the current view.  
Temporal Trends: * An area chart tracks accidents from January 2022 through early 2025, showing a notable dip in reported incidents toward the start of 2025.  
A bar chart analyzes accidents by Day of the Week, revealing that Monday (2,966) and Friday (2,879) are the peak days for incidents.  
Contributing Factors:
Accidents by Cause: Categorizes incidents into primary drivers such as distraction (4,026), overspeeding (4,025), and weather (3,997).  
Environmental Impact: Breaks down accidents by weather, showing that incidents are nearly equally split between clear (6,690), rain (6,677), and fog (6,633) conditions.  
Infrastructure Analysis:
Road Type: Compares accident frequency on urban (6,745), rural (6,639), and highway (6,616) roads.  
Lanes: Analyzes incidents based on road capacity, ranging from 2 to 6 lanes.  
Technical Implementation
Tools Used: Power BI Desktop.  
Data Model: Built on the indian_roads_dataset, utilizing a Star Schema for efficient filtering across regions, causes, and dates.  
Visual Elements: Used a consistent dark-themed UI with cards, donut charts, area charts, and horizontal bar charts for quick scannability.  
Interactivity: Integrated slicers for Region (e.g., South India) and Day of the week to allow for granular data exploration.  

This dashboard serves as a decision-support tool for identifying critical safety interventions by highlighting the specific causes and locations where road accidents are most prevalent.
